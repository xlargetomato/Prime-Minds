#  Prime Minds

An educational puzzle game inspired by Thurstone’s Primary Mental Abilities theory.  
The game is designed to improve mental skills through interactive challenges.

##  Features
- Math problem solving
- Pattern recognition puzzles
- Logical thinking challenges
- Simple and interactive gameplay

##  Concept
This game is based on Thurstone's theory, which focuses on different mental abilities such as reasoning, numerical ability, and perception.

##  Goal
To create a fun and educational experience that helps users practice and develop their cognitive abilities.

##  Technologies Used
- C#
- Unity
- Blender

##  Educational Purpose
This project was developed for an Educational Psychology course to demonstrate mental abilities through gameplay.
